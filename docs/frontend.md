# Frontend

Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, TanStack Query. Código en `frontend/`.

## Mobile first

La mayoría llega desde el celular. Diseño desde ~375px, escalando con `sm`/`md`/`lg` de Tailwind. Acciones principales abajo, áreas táctiles de 44px, tarjetas de una columna, formularios cortos.

### Lobby

| Pieza              | Qué muestra                                                                                                                                                                                                                              |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Encabezado         | "Lobby" y la campana a la izquierda (solo con sesión; badge con las no leídas: nada en 0, el número de 1 a 9, "9+" desde 10; lleva a `/notificaciones`), "Mis partidas" a la derecha |
| Tarjeta de perfil  | Inicial con check si el correo está verificado, nombre, género, categoría y subnivel. Arriba, tu ubicación: desplegable de zonas, "Usar mi ubicación" y un "?" que explica para qué se usa. La zona elegida queda en `localStorage`      |
| Menú "Filtros"     | "Ordenar por: Cercanía · Nivel" para ambas pestañas (reglas en [Categorías](reglas-de-negocio.md#categorías) y [Sucursales](reglas-de-negocio.md#sucursales)). Cercanía se desactiva sin ubicación ni zona                               |
| Tarjeta de partido | Toda la tarjeta abre el detalle. Estado, categoría, fecha, sucursal con distancia y etiquetas (cancha, duración, tipo, puestos). En la pestaña Partidos, "Unirme". Tus próximos partidos se cancelan desde el detalle, no desde el lobby |
| Tarjeta de jugador | Inicial con check de verificado, sucursal con distancia, nombre, género, categoría, subnivel, horario y "¿Juegas?"                                                                                                                       |

## Términos y privacidad

- `TermsGate` (en `app/layout.tsx`, dentro de `SessionProvider`) muestra `TermsDialog` bloqueante si el usuario tiene `termsAccepted: false`, en cualquier ruta salvo `/privacidad` y `/terminos`.
- `LEGAL_UPDATED_AT` (`lib/legal.ts`) es la fecha legible de `TERMS_VERSION` (`backend/app/services/terms.ts`): se cambian juntas.
- `CookieNotice` solo se monta con `NEXT_PUBLIC_GTM_ID`; recuerda el cierre en `localStorage` y sube sobre las barras fijas (`data-fixed-bottom-bar`).
